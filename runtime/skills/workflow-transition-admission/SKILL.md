# Workflow Transition Admission

Use this Skill only at a decision-bearing workflow boundary. Do not invoke it for ordinary trivial read-only exploration.

1. Build one receipt matching [transition-admission-contract.md](references/transition-admission-contract.md). Source-wide implementation uses v3 with the same scope/state binding as the owner and child dispatch. V2 remains for ordinary non-product boundaries and old same-chat inputs; v1 is historical split-chat compatibility. Neither older schema proves source-wide selection.
2. For a binding material correction, commit/push, CI dispatch, or external apply, bind exact source authority or an independent refutation, closed FCR, frozen S0 plus interaction IDs, planned U0, omission consequence, expected objective delta, cost/rework counterfactual and exact return step. A proposed fix without these inputs is `DIAGNOSE` or `ADVISORY`, not an admitted material transition.
3. The same-chat owner consumes the source-bound decision without claiming that its own control pass is independent review. A higher role never supplies missing source or closure. Preserve evidence on any dependent hold; independent refutation remains a separate key where required.
4. Before diagnosis or repair, search both current masters for the current signature and disposition any known family. Retry a known family only with a changed premise and discriminating prediction.
5. Before a finalized action, bind selected bytes, script when applicable, planned application and outcome capture. Append actual application/effect after execution. A future effect is not pre-action authorization. Selection/read alone is not use or benefit. A repeated mechanical family requires the deterministic script or another constrained representation.
6. Immediately before a released external action, bind current action-relevant state. `STALE` or `UNKNOWN` returns `REPLAN` only for that action.
7. Monitor at decision windows. Reuse unchanged cursors and evidence. Fixed polling or narration without a decision delta is not admitted. Slow work with objective evidence progress may return `WAIT`.
8. Bind COORDINATED-WORK task/chat/lease/resource or BOUNDED-SUBAGENT parent lease/resource ownership. An independent reviewer cannot implement its reviewed candidate. Reconcile old leases and unknown effects before migration; v1 formal-worker restrictions do not block the new same-chat owner.
9. Preserve scenario recomposition and the consumer target. A material edit binds its semantic lock, relational claims, recomposition witness, unresolved relations, consumer claim IDs and final oracle. The script checks only reference/set presence; it never claims those semantics are correct.
10. Reassess allocation only when job shape changes. Bind and open actual view/result files, hashes, admitted decision and configuration; references or caller labels alone are insufficient. Auxiliary routes must name the mandatory outcome left unproven if omitted, time saved and retirement condition.
11. After a correction episode, record induced/avoided rework, status-only cost, known-cause rediscovery, Skill recurrence, scenario omission, role violation, consumer result and objective delta as observed/unavailable/not-applicable. Feed a lifecycle revise/merge/narrow/retire/no-change candidate; the episode never self-activates a semantic policy change.

Run:

`python -B scripts/transition_admission.py --input <receipt.json>`

The script validates presence, identities, enumerated states and bounded cross-field relations only. It cannot prove source fidelity, FCR correctness, scenario or interaction completeness, impact safety, Skill semantics, external freshness truth, monitoring value, or objective outcome.

V3 consumes the sibling lifecycle `work_phase.py` decision before any lightweight bypass. `EDIT` must be implementation or grouped findings repair. Construction feedback cannot reclassify external apply, push, CI or an existing regression correction as an inexpensive local probe. Hold only the dependent transition; retain the already observed effects and continue independent safe work. The action gate and phase selection are separate necessary checks, not permission substitutes.
