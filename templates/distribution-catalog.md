# Distribution catalog reference

Record ID: `OIF-DISTRIBUTION-CATALOG`

The included Skill Book provides eight generic capabilities: objective
continuity, source-bound resolution and application, measured learning,
transition admission, scenario/recomposition closure, objective control,
optional native PowerShell preflight and legacy split-task status recovery.

Generate a hash-bound project-origin registry with `python tools/catalog.py
--output ../registry.json`. Its project root is `runtime/skills` in this
distribution. The generated registry links to this public distribution record;
it does not contain the adopter's global or project history. Supply this file
alongside your own relevant master records when validating the distribution.

Selection describes what applies. Read the selected files, bind any action to
its actual input and result, and record whether the next consumer benefited.
Do not copy an active or measured status from this package into a claim that a
particular deployment or task has already used it successfully.
