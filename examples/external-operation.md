# Example: External Operation

Scenario: Publish a project repository.

Before the external write:

- Verify target account and repository name.
- Confirm the candidate commit, tree, license, README, privacy scan, and audit receipt.
- Confirm no private remote is attached.
- Project action eligibility for a public push.
- Push once using a non-force action.
- Read back visibility, default branch, commit, inventory, and key rendered content.

The public readback is external evidence. Local tests alone do not prove publication.
