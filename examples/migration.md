# Example: Migration

Scenario: Move a workflow from one runtime to another.

Define the semantic authority boundary first. The old system is authoritative for externally observable decisions, state effects, recovery behavior, and consumer outcomes. It is not automatically authoritative for implementation language, locks, object layout, timing, or internal queues.

Map every preserved behavior to an evidence route and proof ceiling. Keep unresolved boundary-state continuity claims visible until a bridge or runtime observation closes them.
