# Code of Conduct

We aim to keep this project practical, respectful, and evidence-aware.

Participants are expected to:

- Be kind and direct.
- Critique mechanisms and evidence, not people.
- Keep examples public-safe.
- Avoid exaggerated claims.
- Respect maintainers' decisions about scope and adoption cost.

Unacceptable behavior includes harassment, doxxing, credential disclosure, and attempts to publish private operational material.
