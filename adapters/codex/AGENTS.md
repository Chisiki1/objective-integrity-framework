# Project Agent Guidance

Use Objective Integrity Framework as project-local guidance.

Before material work, extract the source-bound objective and acceptance criteria. Keep tests, audits, blockers, safety checks, subagents, and learning records subordinate to the requested outcome. Link every material action to the source claim it advances and the proof ceiling it can support.

Keep one same-task primary owner by default and use read-only independent review where it materially improves assurance. Preserve durable objective state project-locally when work can resume, compact, queue, retry, or leave an uncertain effect.

Reuse and read the logical-task objective ledger on later instructions, material results, completed items, resume/compaction and final delivery. Keep one source-wide completion scope: build all required parts and connections, collect safe whole-stage findings, repair shared causes together, then accept the actual result. Construction feedback is not premature acceptance.

Carry eligible within-authority improvements into their next real use without another prompt. Preserve original operation results and change the actual next caller when a useful correction is established; include required scripts and resources in a Skill package. Continuing actors personally reconcile affected methods at safe resume boundaries. Organize touched current knowledge across every relevant current location, replacing its disposition with complete backing history retained; compare structural simplification when recurrence or integration cost justifies it. Pending condition amendments hold only dependent changes. Use actual host capabilities and current primary evidence where they can change a decision.

Use `.agents/skills/objective-integrity` for progressive workflow guidance. Load its continuity, high-assurance, or Skill Book references only when the current work needs them. Do not install or modify global configuration from this file.
