# Project Agent Guidance

Use Objective Integrity Framework as project-local guidance.

Before material work, extract the source-bound objective and acceptance criteria. Keep tests, audits, blockers, safety checks, subagents, and learning records subordinate to the requested outcome. Link every material action to the source claim it advances and the proof ceiling it can support.

Keep one same-task primary owner by default and use read-only independent review where it materially improves assurance. Preserve durable objective state project-locally when work can resume, compact, queue, retry, or leave an uncertain effect.

Use `.agents/skills/objective-integrity` for progressive workflow guidance. Load its continuity, high-assurance, or Skill Book references only when the current work needs them. Do not install or modify global configuration from this file.
