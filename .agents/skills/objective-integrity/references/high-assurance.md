# High-Assurance Workflow

Use for public release, external action, production mutation, privacy, safety, financial, long-running, or recovery-sensitive work.

Add:

- Blind-first scenario or product challenge.
- Public/privacy threat model.
- Implementation-complete snapshot.
- Independent privacy, usability, and semantic non-drop audits as applicable.
- Partitioned deterministic checks.
- Final release-candidate audit.
- Pre-action eligibility projection.
- Post-action readback.
- Effect episode with empirical limits.
