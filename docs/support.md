# Help and feedback

Start with the [adoption guide](adoption.md), [troubleshooting](troubleshooting.md)
and [release guide](releases.md). For a general question, bug or useful improvement,
[open an issue](https://github.com/Chisiki1/objective-integrity-framework/issues/new/choose).
The templates help capture the requested result, exact version and smallest
synthetic reproduction. A plain question is welcome; do not create a large
evidence packet when a short example explains the problem.

Include your OS, Python version when relevant, adoption mode and the first error.
Describe expected versus actual behavior and whether any files changed. Keep
original logs locally; share only a sanitized excerpt. Never upload credentials,
private task ledgers, user prompts, generated memory or unrelated project data.

For sensitive issues, follow the [security policy](../SECURITY.md), not a public
bug report. Contributions follow [CONTRIBUTING.md](../CONTRIBUTING.md) and the
[code of conduct](../CODE_OF_CONDUCT.md). Support is community-based; feature
requests are evaluated by usefulness, compatibility and maintenance cost.
