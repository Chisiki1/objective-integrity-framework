# Governance and Self-Improvement

Objective Integrity Framework treats self-improvement as an evidence-bearing change, not a reward for writing more rules.

## Learning Records

Use two layers of learning ledgers when the cost is justified:

- A project master preserves exact project evidence, raw observations, failed alternatives, and local return steps.
- A global master receives sanitized reusable knowledge, applicability, proof ceiling, and recurrence constraints.

The records are support infrastructure. They are never a substitute for the current objective, source, artifact, runtime, or external state.

## Skill Book Feedback

When a reusable skill or deterministic helper is invoked, record its effect separately from the fact that it was selected. A useful record distinguishes planned and actual objective delta, planned and actual evidence delta, consumer result, side effects, rollback, cost, rework, counterevidence, and proof ceiling.

Project records retain exact effects and failed alternatives. Global records receive only sanitized reusable families, aggregate effect, applicability, invalidation trigger, and proof ceiling. This keeps the public lesson useful without turning private task details into shared guidance.

## Improving the Framework

Before adding a new permanent mechanism, show:

- The existing invariant that failed or could not express the case.
- The reusable failure family.
- Expected outcome or cost improvement.
- Independent challenge or representative replay.
- No-drop preservation of older obligations.
- Rollback conditions.

Structural design evidence should be reported separately from measured empirical improvement.
