# The 10-Minute Core Loop

Use this loop when you want the smallest useful version of Objective Integrity Framework.

## 1. Name the Outcome

Write one sentence for the requested observable result. Then list acceptance criteria, constraints, and things that are only means.

## 2. Name the Forbidden Substitute

Write what would look productive but would not satisfy the request. Common substitutes are test completion, audit completion, blocker cleanup, documentation polish, or safe early exit.

## 3. Choose the Next Outcome Link

Before a material action, state which source-bound claim it advances and what would fail or remain unproven if the action were skipped.

## 4. State the Evidence Limit

Name what the action can prove. A local check, component test, review, runtime observation, and public readback each have different evidence limits.

## 5. Preserve the Result

After the action, record the actual outcome, what changed, what remains open, and the next eligible objective-bound step.

This loop is enough for many small tasks. Use the Standard or High-Assurance profile when the work involves implementation, correction, public release, external action, privacy, production, long-running state, or material harm.
